# Category tree source

**Status: sample test data (placeholder).** This directory currently holds a small, hand-made, Tiki-shaped dataset (17 categories, 7 attributes) so the FEAT-014 loader can be developed and tested. It is **not** the owner-accepted Tiki taxonomy.

Still to come from the owner (NFR-LEG-002, BR-014-12, D-9):
- the real Tiki-derived category and attribute files, replacing the files here;
- the owner's written acceptance of using that taxonomy and of linking Tiki's top-level category images;
- the id range reserved for categories the owner adds by hand.

Image URLs in the sample point to `example.com` and do not resolve.
