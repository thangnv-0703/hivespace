# Contracts

Source of truth for every interface between units (dev-standards §6, §6.1, §7). Change the contract first, then the code.

| Folder | What | Tooling |
| :-- | :-- | :-- |
| `openapi/` | Public REST API per service; `shared/components.yaml` holds Money, Error, PageMeta, Id | Spectral lint (`.spectral.yaml`); TS client generated by `@hey-api/openapi-ts` into `web/packages/api-client` |
| `proto/` | Internal gRPC (ADR-0019), one package per service | `buf lint`, `buf breaking`; Go and Python stubs by `buf generate`; .NET stubs by Grpc.Tools at build time |
| `events/` | Event envelope and one schema per event and version (ADR-0002) | JSON Schema 2020-12 |
| `features/` | Shared Gherkin contract tests, one folder per service | Reqnroll (.NET), godog (Go), pytest-bdd (Python) |
| `errors/` | Stable error codes and vi/en messages (FR-LOC-004) | key-parity check in CI |

Generator choices (dev-standards §14 item 5): buf runs project-locally through `npx @bufbuild/buf` (no global install). Go and Python stubs come from the `protoc-gen-go`, `protoc-gen-go-grpc` and `grpcio-tools` plugins listed in `buf.gen.yaml`; .NET stubs are built by Grpc.Tools.

Commands (from `contracts/`):

```bash
npx @bufbuild/buf lint
```

```bash
npx @bufbuild/buf generate
```
